# 工程萬用相機 (Android & Web PWA 工具)

專為營造工程、室內裝修、水電消防、設備巡檢與物業管理打造的**現場拍照、浮水印看板、相簿歸檔與 Word 報告生成工具**。

---

## 🌟 核心功能特色

1. **現場拍照與即時工程銘牌浮水印**
   - 取景時即時預覽工程浮水印銘牌
   - 支援 4 種看板樣式：
     - **現代工程銘牌**（高對比黑底黃/白字，帶階段彩色徽章）
     - **台灣公共工程板**（傳統綠白雙色表格驗收看板）
     - **底部通欄工務條**（橫向資訊條，視野開闊）
     - **極簡角落印章**（緊湊右上角標記，不遮蔽施工細節）
   - 自動即時年月日時分秒
   - 自動 GPS 經緯度與台灣即時地址逆解析
   - 快速切換施工階段：`施工前`、`施工中`、`施工後`、`隱蔽查驗`、`自主檢查`、`材料進場`、`缺失改善`
   - 手機相機前後鏡頭切換、閃光燈控制、支援相簿照片匯入補打浮水印

2. **工程專案（案場）分類與相簿管理**
   - 建立與管理多個案場（工程名稱、業主/起造人、承造廠商、預設地址）
   - 相片自動依案場分類與時間排序
   - 施工階段標籤快速篩選（如只看「施工前」或「施工後」）
   - 相片高畫質預覽、單張下載、批次選取與刪除

3. **一鍵輸出 Word (.docx) 工程照片紀錄報告**
   - 勾選照片即可一鍵生成 Word 檔案
   - 支援兩種主流工程排版：
     - **A4 一頁 2 張**（大尺寸照片 + 標準工程檢驗表格，公文/監造送審首選）
     - **A4 一頁 4 張**（精簡 2x2 排版，節省紙張，適合進度清冊）
   - 自動嵌入專案資訊、拍攝時間、施工階段、查驗說明、頁碼與頁首頁尾

4. **100% 離線可用與隱私保護**
   - 採用本機 IndexedDB 資料庫
   - 所有相片與 Word 文件完全在手機本機運算與儲存，不需傳送至外部伺服器，保障工程商業隱私

## 🚀 如何在 Android（安卓）手機上使用

### 方式 A：手機瀏覽器直接使用 & 加入主畫面（最推薦、免安裝）
1. 確認手機與電腦連線同一個 Wi-Fi 網路。
2. 在 Android 手機上的 Chrome 瀏覽器打開：
   ```
   http://192.168.1.110:5173
   ```
3. 在 Chrome 右上角點選 **選單（三個點）** -> 點選 **「加到主螢幕」** 或 **「安裝應用程式」**。
4. 手機桌面就會出現「工程相機」App 圖示，打開即可擁有像原生 App 一樣的全螢幕相機操作體驗！

## 📦 如何打包成 Android 原生 APK（選用）

如需編譯出標準 `.apk` 安裝檔，可使用 Capacitor：

```bash
# 1. 安裝 Capacitor 依賴
npm install @capacitor/core @capacitor/cli @capacitor/android

# 2. 初始化 Capacitor
npx cap init "工程萬用相機" "com.engineering.camera" --web-dir dist

# 3. 建置前端
npm run build

# 4. 加入 Android 原生專案
npx cap add android

# 5. 同步資源並在 Android Studio 開啟
npx cap sync
npx cap open android
```
在 Android Studio 中點選 **Build > Build Bundle(s) / APK(s) > Build APK(s)** 即可獲得 APK 安裝檔。
